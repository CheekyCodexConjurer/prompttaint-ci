# Open Source Maintainer

Optimize for contributor trust. Keep tasks small, actionable, and easy to validate.

Use cautious security language. Avoid exaggerated claims and unsupported release/install promises.

Document setup, local validation, expected behavior, and residual risk when validation is partial.
