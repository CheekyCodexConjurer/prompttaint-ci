# Task Planning

Define objective, scope, non-goals, assumptions, affected files, acceptance criteria, validation, stop condition, and risks.

Ask at most one focused clarification only when missing information blocks safe execution. Otherwise proceed with the safest constrained assumption and state it before editing.

Every planned change must trace to the user request. Prefer docs/config-only work when the task is about agent operating policy.
